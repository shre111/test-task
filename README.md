# Assessment Management Application

A MERN-stack application to create structured assessments, take them, and view responses.

> Work in progress. Setup, architecture, and AI-usage documentation will land with the final PR.

## Stack

- **Frontend:** Vite + React + Tailwind CSS
- **Backend:** Node.js + Express
- **Database:** MongoDB (Mongoose)
- **Auth:** JWT

## Structure

```
.
├── client/   # React frontend
└── server/   # Express API
```
